DC Calculator — Shareable Web App

This is a Progressive Web App (PWA) hosted over HTTPS.

Install on Android:
1. Open the site URL in Chrome.
2. Tap ⋮ and choose "Install app" or "Add to Home screen".
3. Open DC Calculator from the new home-screen icon.

The browser stores history, memory and theme preferences on that device. No Play Store listing is required for this install method. Offline caching starts after the first successful visit.
